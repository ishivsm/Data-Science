# NumPy Broadcasting and Vectorization

These are two **very important NumPy concepts**, especially for Data Science and Machine Learning.

---

# 1. Broadcasting

### What is Broadcasting?

**Broadcasting** allows NumPy to perform operations between arrays of **different shapes**.

Instead of manually repeating values, NumPy automatically expands the smaller array when the shapes are compatible.

### Simple example

```python
import numpy as np

arr = np.array([10, 20, 30, 40])

result = arr + 5

print(result)
```

Output:

```text
[15 25 35 45]
```

You didn't write:

```python
[10, 20, 30, 40] + [5, 5, 5, 5]
```

NumPy automatically broadcasts `5`:

```text
[10 20 30 40]
       +
[ 5  5  5  5]
       =
[15 25 35 45]
```

---

# 2. Broadcasting with 2D Arrays

```python
arr = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

result = arr + 10

print(result)
```

Output:

```text
[[20 30 40]
 [50 60 70]]
```

The `10` is applied to every element.

---

# 3. Broadcasting a 1D Array

Consider:

```python
arr = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

x = np.array([1, 2, 3])

result = arr + x

print(result)
```

Output:

```text
[[11 22 33]
 [41 52 63]]
```

Conceptually:

```text
10  20  30       1  2  3
40  50  60   +   1  2  3
                 ↓
11  22  33
41  52  63
```

The `[1, 2, 3]` is broadcast across each row.

---

# 4. Broadcasting with a Column

```python
arr = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

x = np.array([
    [1],
    [2]
])

result = arr + x

print(result)
```

Output:

```text
[[11 21 31]
 [42 52 62]]
```

Here:

```text
[1] → applied to first row
[2] → applied to second row
```

---

# 5. Broadcasting Rules

NumPy compares array dimensions **from right to left**.

Two dimensions are compatible when:

1. They are equal, or
2. One of them is `1`.

Example:

```text
(2, 3)
(3,)
```

NumPy treats `(3,)` like:

```text
(1, 3)
```

So they are compatible.

Another example:

```text
(2, 3)
(2, 1)
```

These are also compatible.

But:

```text
(2, 3)
(2, 2)
```

are **not compatible** because:

```text
3 ≠ 2
```

# 6. Vectorization

### What is Vectorization?

**Vectorization means performing operations on an entire NumPy array at once instead of using Python loops.**

### Without vectorization

```python
arr = [10, 20, 30, 40]

result = []

for x in arr:
    result.append(x * 2)

print(result)
```

Output:

```text
[20, 40, 60, 80]
```

### With NumPy vectorization

```python
import numpy as np

arr = np.array([10, 20, 30, 40])

result = arr * 2

print(result)
```

Output:

```text
[20 40 60 80]
```

Much simpler.

---

# 7. Vectorized Operations

You can perform many operations directly on arrays.

```python
arr = np.array([10, 20, 30, 40])

print(arr + 5)
print(arr - 5)
print(arr * 2)
print(arr / 2)
print(arr ** 2)
```

Output:

```text
[15 25 35 45]
[ 5 15 25 35]
[20 40 60 80]
[ 5. 10. 15. 20.]
[ 100  400  900 1600]
```

---

# 8. Vectorized Mathematical Functions

NumPy also provides vectorized mathematical functions.

```python
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))
```

Output:

```text
[1. 2. 3. 4.]
```

Another example:

```python
arr = np.array([1, 2, 3])

print(np.square(arr))
```

Output:

```text
[1 4 9]
```

---

# 9. Vectorization with Conditions

You can combine vectorization with Boolean masking.

```python
arr = np.array([10, 20, 30, 40, 50])

result = arr[arr > 25]

print(result)
```

Output:

```text
[30 40 50]
```

No loop is required.

---

# 10. `np.where()` — Very Useful

`np.where()` is another powerful vectorized operation.

Suppose:

```python
marks = np.array([35, 70, 45, 90, 20])
```

We want:

* `Pass` if marks >= 40
* `Fail` otherwise

```python
result = np.where(marks >= 40, "Pass", "Fail")

print(result)
```

Output:

```text
['Fail' 'Pass' 'Pass' 'Pass' 'Fail']
```

This is very useful in Data Science.

---

# Broadcasting vs Vectorization

| Concept           | Meaning                                                            |
| ----------------- | ------------------------------------------------------------------ |
| **Broadcasting**  | Allows operations between compatible different-shaped arrays       |
| **Vectorization** | Performs operations on entire arrays without explicit Python loops |

### Example of both together

```python
import numpy as np

salary = np.array([
    [30000, 40000, 50000],
    [35000, 45000, 55000]
])

bonus = np.array([1000, 2000, 3000])

new_salary = salary + bonus

print(new_salary)
```

Output:

```text
[[31000 42000 53000]
 [36000 47000 58000]]
```

Here:

**Broadcasting** → `[1000, 2000, 3000]` is applied to every row.

**Vectorization** → the addition happens to the entire array without a `for` loop.

---

## The key idea

```text
Broadcasting
     ↓
Different shapes can work together
     ↓
NumPy automatically expands dimensions

Vectorization
     ↓
Operate on entire arrays
     ↓
Avoid explicit Python loops
     ↓
Cleaner + usually faster numerical computation
```

For your ML preparation, make sure you understand **broadcasting + vectorization + `axis` + `reshape`** together. These four concepts appear frequently when working with feature matrices and preprocessing.
